# Химчистка 75 — независимый демосайт

Статический сайт для демонстрации дизайна, **не официальный ресурс компании**. В нём нельзя отправить реальные заявки: можно подготовить и скопировать текст запроса. Фотографии остаются в браузере и никому не передаются.

## Как открыть

- Для локального просмотра используйте автономный файл `Himchistka75_preview.html` (поставляется отдельно). Для исходного `index.html` рекомендуется локальный HTTP-сервер, например `python -m http.server 8000` внутри папки проекта: некоторые браузеры ограничивают внешние SVG-иконки по `file://`.
- Для GitHub → Vercel загрузите **содержимое** этой папки в корень репозитория, подключите репозиторий к Vercel.
- Preset: `Other`, Root Directory: `.`, Build Command: **пусто**, Output Directory: **пусто**, Install Command: **пусто**.
- Выберите свободный адрес, например `himchistka75-demo.vercel.app` (доступность не подтверждена).

## Файлы

- `index.html` — разделы сайта, разметка и SEO-статус демо.
- `styles.css` — адаптивный дизайн, анимации и мобильная навигация.
- `app.js` — подбор нескольких предметов, превью фото, сравнение иллюстраций, копирование запроса.
- `config.js` — основные публичные контакты и сведения компании, которые необходимо перепроверить перед официальным запуском.
- `assets/illustrations/` — 13 оригинальных SVG иллюстраций.
- `assets/icons.svg` — 39 SVG-символов, которые переиспользуются в интерфейсе.
- `assets/favicon.svg` — значок сайта.
- `robots.txt` — запрет индексации демоверсии.

## Особенности

- Адаптивная сетка с мобильным меню и плавающим CTA.
- Отдельный вид для бизнеса, FAQs, публичные контакты, честное обозначение деморежима.
- Выбор до 12 разных позиций, до 20 единиц каждой, 3 фото до 6 МБ каждое; JPG/PNG/WebP.
- Обработка фото строго локальная через `URL.createObjectURL`, после удаления URL освобождается.
- Автономный HTML-превью не загружает внешние CSS, JS, шрифты или иллюстрации. Внешние контакты открываются только по нажатию.
- `prefers-reduced-motion`, доступные поля ввода, нативный FAQ, SVG и отсутствие внешних библиотек.
